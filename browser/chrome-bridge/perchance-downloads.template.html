Setup: Windows & Mac
  1. Download and extract the ZIP into a folder you will keep. In Chrome, open chrome://extensions, enable Developer mode, select Load unpacked, and choose the extension folder containing manifest.json. Choose a folder, not the ZIP or a file. Pin Kronos TradingView Bridge.
  2. Open your TradingView chart and Pine Editor. Create a new Indicator, paste the supplied code, save privately as Kronos Forecast Bridge, then Add to chart. Keep your other indicators.
  3. Reload this generator and TradingView after installing the extension. Load market data, load the model, then generate a forecast.
  4. In TradingView · Chrome bridge, match the exact exchange-qualified symbol (for example OKX:BTCUSDT) and the chart timeframe. Click Send to Chrome bridge.
  5. Open the Chrome extension popup, select your TradingView chart tab, then click Open indicator settings and apply. Check the indicator's status table. Automatic apply is optional.
Manual fallback & troubleshooting

If the settings adapter fails, use Copy TradingView data in the generator and paste it into the indicator's Forecast payload input. If the extension reports no receiver, reload both tabs. Downloads blocked inside an iframe? Open the generator directly, or use the public bridge release.

The extension stores forecast data in this Chrome profile and accesses Perchance, localhost, and TradingView chart pages. It does not place trades. The model runs in your browser; no desktop installer or Polygon key is required. Stock sessions and provider candle boundaries must match your chart. Forecast timestamps use UTC. TradingView UI changes can break automatic transfer. Chrome desktop installation is required; this extension cannot run in Chrome on iPhone.
